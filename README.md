# IPL 2025 Analytics Dashboard

An interactive IPL 2025 analytics dashboard built using **Microsoft Power BI** to explore team standings, player performance, batting and bowling records, and tournament statistics through visual reports.

## Project Overview

This dashboard brings IPL team and player statistics together in a navigable report. It includes pages for an overview, points table, squads, and individual performance records.

## Dashboard Sections

- **Overview:** Summary cards and tournament information.
- **Points Table:** Team standings, matches played, wins, losses, points, and net run rate (NRR).
- **Squads:** Player listings with team and player-role information.
- **Batting Records:** Runs, fours, sixes, centuries, half-centuries, highest scores, and fastest fifties and hundreds.
- **Bowling Records:** Wickets, dot balls, economy rate, bowling average, and best bowling figures.

## How to View

1. Clone or download this repository.
2. Open the `.pbix` report file using **Microsoft Power BI Desktop**.
3. Use the report navigation and available filters to explore the dashboard.

> **Note:** The repository should include the Power BI `.pbix` file and any data files required to refresh the report. The PDF preview can be included as a read-only preview.

## Project Goals

- Present cricket statistics in an interactive and accessible format.
- Compare team standings and player records.
